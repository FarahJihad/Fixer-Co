# Fixer.Co

Fixer.Co is a home maintenance service platform that helps users find suitable fixers based on service type, location, availability, rating, and starting price.

## Features

- Browse home maintenance services
- Find and filter Fixers
- Use current location to view nearby Fixers
- Sort by recommended, nearest, highest rated, or lowest price
- View Fixer profiles
- Submit service requests
- Contact Fixer.Co
- Apply to become a Fixer
- MySQL database integration
- Responsive interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL
- MAMP
- Font Awesome
